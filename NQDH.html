About This Application

This Quran Explorer application is built using the Quran.com API v4, an open-source RESTful service providing comprehensive Quranic data. Features include full Arabic text in multiple scripts (Uthmani, IndoPak, Imla'i), 100+ translations, word-by-word analysis, audio recitations from renowned Qaris, and color-coded Tajweed rules.

Primary Translation: English (M.A.S. Abdel Haleem) - Always displayed
Secondary Translation: Customizable (Default: Bengali - Abu Bakr Zakaria)
