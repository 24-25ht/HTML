ℹ️ About Quran Explorer

This Quran Explorer application is built using the Quran.com API v4, an open-source RESTful service providing comprehensive Quranic data.

Features include:

  • Full Arabic text in multiple scripts (Uthmani, IndoPak, Imla'i)
  • 100+ translations in various languages
  • Word-by-word analysis with transliteration
  • Audio recitations from renowned Qaris
  • Color-coded Tajweed rules
  • Tafsir (commentary) from multiple sources
